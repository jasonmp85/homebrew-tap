# Jasonmp85 Tap

## How do I install these formulae?

`brew install jasonmp85/tap/<formula>`

Or `brew tap jasonmp85/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jasonmp85/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
